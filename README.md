# Docker Learning

Welcome to my Docker Learning repository.

This repository contains my notes, hands on practice, exercises, experiments, and practical implementations while learning Docker. It serves as a personal knowledge base where I document Docker concepts through practical use.

The primary focus of this repository is to understand containerization, learn how Docker works, and build a strong foundation for DevOps, Cloud, Backend Development, and AI Platform Engineering.

---

## Purpose

The purpose of this repository is to:

* Learn Docker through hands on practice.
* Understand containerization and why it is used.
* Learn how Docker images and containers work.
* Create and manage Docker containers.
* Write and understand Dockerfiles.
* Practice exposing applications through Docker ports.
* Understand Docker volumes and persistent data.
* Learn Docker networking.
* Use Docker Compose for multi-container applications.
* Develop practical containerization skills for real world projects.
* Build a strong foundation for DevOps, Cloud, and AI Platform Engineering.

## Repository Philosophy

Rather than only memorizing Docker commands, I prefer learning Docker by building, running, and experimenting with containers.

Every concept is practiced through commands, exercises, small implementations, and real examples so that I can understand how Docker works and revisit the concepts whenever needed.

---

## Learning Approach

* Learn a Docker concept
* Understand how it works
* Practice Docker commands
* Build and run containers
* Experiment with images and containers
* Work with Dockerfiles
* Practice networking and persistent storage
* Build multi container applications
* Document important concepts and commands
* Review mistakes and difficult concepts
* Organize the learning material properly
* Commit the progress to GitHub
